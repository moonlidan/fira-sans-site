Учебный проект: вёрстка лендинга о шрифте «Fira sans».
Сверстаны секции: заголовок, история, начертания, языки и конец.

## Как открыть
Откройте `index.html` в браузере.

## Структура папок
- `css/` — стили (`styles.css` подключает `reset.css`, `fonts.css`, `layout.css`)
- `images/` — изображения
- `fonts/` — шрифт «Fira sans»
